# RFID based Contactless Canteen System
This is an Arduino based MiniProject for creating a RFID system which uses RF cards to track credit (prepaid) and place orders.

## Goal
- Reduce the waiting time in queues
- Reduce confusion caused by lack of internet in the location
- Increase overall efficiency by having multiple stations
- Standout as a modern method of handling daily transactions

## Hardware
- Arduino UNO
- MFRC522
- MIFARE Classic 1K Cards

## Software
- Server - Python Flask
- Scripting - C++ for Arduino
- Webpage stack - JS, JSON, HTML, CSS
